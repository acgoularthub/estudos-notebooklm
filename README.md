# Miniguia de Estudos: Explorando o NotebookLM

Bem-vindo ao repositório **miniguia-estudos-notebooklm**! Este espaço foi criado para documentar e organizar os meus estudos sobre o **Google NotebookLM**, uma ferramenta revolucionária de anotações e pesquisa baseada em inteligência artificial.

## Contexto e Objetivos

O NotebookLM propõe uma nova forma de interagir com documentos, oferecendo um assistente de IA "ancorado" (grounded) nas fontes que o usuário fornece. O assunto de interesse escolhido para este caderno temático é **As Capacidades e Aplicações Práticas do NotebookLM na Pesquisa Acadêmica e Produção de Conteúdo**.

**Objetivos de Estudo:**
1. Compreender o funcionamento básico e a arquitetura de *grounding* do NotebookLM.
2. Identificar as melhores práticas para organizar fontes (PDFs, textos, links) dentro da ferramenta.
3. Desenvolver e documentar técnicas de engenharia de prompts específicas para extrair resumos, insights e conexões entre diferentes documentos.
4. Criar um fluxo de trabalho (workflow) eficiente para transformar leitura passiva em conhecimento estruturado.
